# Crazyflie 自穩模式遙控測試工具 (RC Stabilized Test)

`rc_stabilized_test.py` 是一個基於 Python 與 Pygame 開發的圖形化遙控測試工具。該程式允許使用者透過 **Xbox 遊戲手把 (Gamepad)** 以「自穩模式 (Self-Stabilized / Attitude Mode)」手動遙控 Crazyflie 無人機，並在電腦螢幕上即時視覺化搖桿狀態與控制指令數值。

此工具直接發送姿態目標 (Roll, Pitch, Yaw Rate, Thrust) 給 Crazyflie 的內建 Stabilizer 任務，由飛控板的 PID 控制器負責保持機身平衡。

---

## ✨ 程式功能特色

1. **直觀的圖形化介面 (GUI)**
   - 使用 Pygame 繪製雙搖桿的即時位置。
   - 即時顯示當下傳送給無人機的數值 (Thrust, Roll, Pitch, YawRate)。
2. **安全機制與硬體限制**
   - **最大推力限制**：推力上限被鎖定在 `26000` (約 53% 輸出)，避免在室內測試時推力過大暴衝。
   - **姿態角度限制**：最大滾轉與俯仰角限制為 `25°`。
   - **死區設定 (Deadband)**：過濾手把搖桿回中的機械微小虛位，防止無人機異常漂移。
   - **怠速與解鎖 (Arming)**：具備馬達解鎖與上鎖邏輯，怠速推力設定為 `5000`。
   - **緊急停止 (Emergency Stop)**：一鍵切斷動力輸出。
3. **Mode 1 操控佈局**
   - 預設綁定為俗稱「日本手」的 Mode 1 配置（右油門）。

## 🛠️ 環境與前置需求

1. **硬體需求**：
   - Crazyflie 無人機與 Crazyradio PA。
   - 一支標準 Xbox 控制器（或其他相容的 XInput 遊戲手把），請確認已連接至電腦。
2. **軟體環境**：
   - Python 3.x
   - 安裝必要的 Python 套件：
     ```bash
     pip install pygame cflib
     ```

## 🎮 操控方式 (Mode 1 佈局)

| 控制器按鍵 / 搖桿 | 無人機動作對應 | 說明 |
| :--- | :--- | :--- |
| **左搖桿 (上 / 下)** | **Pitch (俯仰)** | 控制無人機前進 / 後退 |
| **左搖桿 (左 / 右)** | **Yaw (偏航)** | 控制無人機機頭左轉 / 右轉 |
| **右搖桿 (上 / 下)** | **Thrust (油門)** | 控制推力 (上升 / 下降) |
| **右搖桿 (左 / 右)** | **Roll (滾轉)** | 控制無人機向左 / 向右平移 |
| **左肩鍵 (LB)** | **Arm / Disarm (解鎖)** | 按下以解鎖馬達。解鎖後推進油門即可起飛。 |
| **右肩鍵 (RB)** | **Emergency Stop (急停)**| 【危險時使用】立即停止馬達轉動並鎖死操控。 |
| **鍵盤空白鍵 (Space)**| **Emergency Stop (急停)**| 同上，方便在沒有抓穩手把時用鍵盤緊急停機。 |

> 💡 **提示**：除了實體手把，您也可以在程式 GUI 視窗上用滑鼠點擊 `ARMED/DISARMED` 或 `EMG. STOP` 按鈕來觸發狀態切換。

## 🚀 如何執行

1. 先將 Crazyflie 開機，並將其放置於空曠平坦的地面。
2. 確認 `rc_stabilized_test.py` 原始碼中的連線 `URI`（預設為 `radio://0/79/2M`）與您的無人機相符。
3. 執行程式：
   ```bash
   python rc_stabilized_test.py
   ```
4. 程式執行後會彈出黑色背景的圖形控制視窗。
5. 按下 Xbox 手把的 **LB 鍵** 進行解鎖（馬達開始怠速運轉）。
6. 緩慢向上推動右搖桿 (Thrust) 起飛。

## ❓ 常見問題

### Q: 為什麼我按下解鎖後，馬達只轉了幾秒鐘就自動停了？
這是 Crazyflie 韌體內建的**安全防護機制 (Spin-up Timeout)**。
- 飛控內部有一個 **2 秒** 的安全倒數計時器。
- 解鎖時，程式會輸出 `IDLE_THRUST = 5000` 的推力讓馬達微轉。但若該推力未達飛控設定的起飛門檻 (例如 `powerDist.idleThrust = 7000`)，飛控會認為您「解鎖了卻沒有要起飛」。
- 為了避免危險，若 2 秒內油門未向上推超過起飛門檻，飛控就會**強制作廢這次解鎖**並自動關閉馬達。

**解決方案 (二選一)：**
1. **立刻起飛 (推薦)**：解鎖後，請在 2 秒內向上推動油門 (Thrust) 搖桿至起飛動力，只要飛控認定已經進入飛行狀態，自動上鎖倒數就會取消。
2. **修改腳本怠速值**：如果您只是想在地面長時間測試馬達轉動，請開啟 `rc_stabilized_test.py`，將 `IDLE_THRUST = 5000` 調整為較高的數值 (例如 `8000`)，讓送出的推力超過系統門檻，就能騙過飛控保持常轉了。

## ⚠️ 安全與注意事項

* **無定位輔助**：本測試為「自穩模式」，無人機只會保持水平，**不會自動定高或定點懸停**。在沒有安裝/啟用 Flow Deck 或定位系統的狀態下，無人機在空中必定會發生水平漂移，需要飛行員時刻透過搖桿修正位置。
* **緊急處置**：若快要撞牆或失控，請毫不猶豫地按下 **RB 鍵** 或鍵盤 **空白鍵** 進行緊急停機。
* **重啟程式**：一旦觸發 Emergency Stop，安全機制會將系統鎖死，必須關閉程式並重新啟動才能再次飛行。
